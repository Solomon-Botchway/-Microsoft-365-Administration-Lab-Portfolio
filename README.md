# -Microsoft-365-Administration-Lab-Portfolio
 Designed, deployed, and administered a Microsoft 365 tenant for a simulated enterprise environment (Solotech Innovations) to develop practical skills in Microsoft 365 Administration, Identity Management, Exchange Online, Teams Administration, SharePoint Online, and Helpdesk Operations.

## Overview

This project simulates a small-to-medium business Microsoft 365 environment called **Solotech Innovations**.

The objective of the lab is to gain hands-on experience with Microsoft 365 administration, Microsoft Entra ID, Exchange Online, identity management, RBAC, security, and helpdesk operations using real-world enterprise scenarios.
